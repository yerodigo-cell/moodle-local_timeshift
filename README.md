# TimeShift (local_timeshift)

TimeShift is a powerful local plugin for Moodle designed to simplify how teachers and administrators manage dates across course activities. Instead of opening each activity settings page one by one, TimeShift provides a clean, centralized table interface to manage your course timeline effortlessly.

## Core Features (Free Version)

The standard version available on Moodle.org includes essential tools to improve your productivity:

* **Centralized View:** See all your course activities, open dates, due dates, and cut-off dates in a single, intuitive table.
* **Inline Editing:** Quickly adjust dates directly from the table without loading individual activity settings pages.
* **Activity Overview:** Easily identify which activities have dates set and which ones don't at a glance.
* **Responsive Design:** A fully mobile-optimized interface for checking your course on the go.

## Requirements

* Moodle 4.1 or later (`2022112800`)

## Installation

### Method 1: Using the Moodle plugin installer
1. Download the ZIP file of this plugin.
2. Log in to your Moodle site as an admin and go to *Site administration > Plugins > Install plugins*.
3. Upload the ZIP file and follow the on-screen instructions.

### Method 2: Manual installation
1. Extract the downloaded ZIP file.
2. Rename the extracted folder to `timeshift` (if it isn't already).
3. Upload the `timeshift` folder to the `local/` directory of your Moodle installation.
4. Log in to your Moodle site as an admin and navigate to *Site administration > Notifications* to complete the installation.

## Usage

Once installed, administrators or teachers (with appropriate permissions) can access TimeShift through the course administration menu. Use the table to review and adjust dates inline. To access bulk actions, click the **"⭐ Discover Pro"** button in the top right corner of the interface.
